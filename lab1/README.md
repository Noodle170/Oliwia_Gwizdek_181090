1. Pobierz pliki projektu na swój dysk.
2. Otwórz terminal i przejdź do katalogu lab1/.
3. Uruchom lokalny serwer HTTP. Jeśli masz zainstalowany język Python w wersji 3, wpisz polecenie:
   ```bash
